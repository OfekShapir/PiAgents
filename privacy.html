PiAgents privacy policy

Last updated: October 31, 2026

Who uses this app

PiAgents is a personal tool used only by its owner, on the owner's own Google account. It is not offered to the public.

What Google data it accesses

  • Gmail (read-only): reads inbox messages to sort them into "important", "contains a task" and "not important".
  • Google Calendar (read-only): reads the list of calendars and their events to plan the owner's day.
  • Calendars created by the app: creates one calendar ("Agent plan") and adds, changes and deletes events only in that calendar.

The app cannot send email, and cannot change or delete any other email or calendar.

How the data is used and stored

  • Data is stored only on the owner's own device.
  • Message text may be sent to Anthropic's Claude API solely to classify and summarize it for the owner. It is not used for any other purpose.
  • Google user data is never sold, shared with third parties for advertising, or used to train AI models.

Google API Services User Data Policy

PiAgents' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the app's local data folder removes everything it stored.
